# Technical Test Automation

This README provides instructions on how to set up the project, run the automated tests, and view the test reports.

## Prerequisites

Before running the project, ensure the following are installed:

- Node.js v24.19.0
- npm v11.17.0
- Git

All project dependencies, including Playwright and Allure reporting packages, are installed through npm.

## Installation

Clone the project repository:
git clone https://github.com/Seagullming/technical-test-automation.git

Navigate to the folder where you cloned the repository:
cd <path-to-your-cloned-repository>/technical-test-automation

- Install project dependencies and playwright framework
npm ci
npx playwright install

## Running Test Cases
Tests could be run through bash command line
npx playwright test tests/guest-checkout.spec.ts

- Or it could be run through Playwright embedded UI tool
npx playwright test --ui

## Test Reports
The project uses Allure as the main report format. The default Playwright HTML report is also available.

Run the required tests first:
npx playwright test
Then generate and open each report follwing steps as below:

### Allure Report (Recommanded)
Allure Report could be generated by running following command
npx allure serve allure-results

### Playwright Default Report
To open the Playwright HTML report:

npx playwright show-report

## Assumptions and Trade-offs
- The selected test products are assumed to remain available on the demo website
- The basket test uses a known product price. This makes the expected result clear, but the test will need to be updated if the website changes the price
- Guest checkout data is stored in CSV so test data can be changed without modifying the test script
- Automation focuses on the main flow and high-priority validation scenarios rather than covering every possible case
- Testing is focused on desktop browsers. Mobile testing is in the scope of this solution
